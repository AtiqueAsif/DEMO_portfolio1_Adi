## 📖 About The Project

This is a fully responsive and interactive portfolio website designed to present my professional profile, projects, and services. The website focuses on clean UI/UX design, smooth animations, and user-friendly navigation.

It is built with a strong emphasis on performance, accessibility, and modern design practices.

---

## ✨ Features

- ⚡ Smooth loading screen animation
- 🌙 Dark mode / Light mode toggle (with localStorage support)
- 🎯 Smooth scrolling navigation with active section highlight
- ⬆️ Back-to-top button
- 🎬 Scroll reveal animations
- ✍️ Typing text animation
- 🎨 Interactive hover effects on cards
- 📱 Fully responsive design (mobile, tablet, desktop)
- 📂 Project showcase section
- 📞 Contact section with form UI

## ⚙️ How It Works

- The **loading screen** displays animations before the main content appears.
- The **navigation bar** allows smooth scrolling between sections.
- The **dark mode toggle** saves user preference using localStorage.
- The **scroll event system**:
  - Highlights active sections
  - Triggers reveal animations
  - Shows back-to-top button
- The **typing animation** dynamically changes text in the hero section.
- The **project and service cards** include hover animations for better interaction.
